# Shifa Pansar Store — English React Demo

A responsive, Vercel-ready React storefront concept for a traditional pansar / herbal goods shop.

## Run locally
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown in the terminal.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Framework preset: Vite
4. Build command: `npm run build`
5. Output directory: `dist`

## Customize before showing the shop owner
Edit `src/main.jsx`:
- Store name and tagline
- Phone / WhatsApp number
- Address and Google Maps URL
- Opening hours
- Product names, images, stock and prices

All products, prices, contact details and location are sample demo content. Replace them with the shop's real information.

## Images
The demo uses direct Unsplash image URLs. The URLs were taken from live Unsplash photo pages and are used as sample photography. For a production store, use the shop's own product photographs or download properly licensed images and host them in the project (for example in `public/images`) so the site does not depend on a third-party image host.

## Important
The wellness section is informational only. Do not advertise products as treatments or cures. Customers with symptoms should consult a qualified healthcare professional.
